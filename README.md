# Simple Interest Calculator

This project is a simple calculator that calculates Simple Interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal Amount
- Rate of Interest
- Time (Years)

## Output

- Simple Interest

## Example

Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2)/100 = 100
